10. Recommended Design Sizes

Instagram

q 1080 x 1350 px -- main feed posts, match graphics, results, player cards, team cards, standings
q 1080 x 1920 px -- stories, reminders, live announcements, results and countdowns

X / Twitter

q 1600 x 900 px -- match graphics, results and announcements

YouTube

q 1280 x 720 px -- thumbnails
q 1920 x 1080 px -- video and community graphics

Discord

q 1920 x 1080 px -- announcements, tournament updates and match graphics

11. Template System & Customization

Generic Template System

q Create modular PSD templates instead of isolated graphics
q Use editable layers for tournament logo, tournament name, game logo, team logos, player photos, sponsor

    logos, colors, typography, scores, statistics, dates and social handles
q Create a master package for each game that can be adapted across tournaments

Customization Service

q MLBB: team, wins, losses, series score and points
q EAFC / eFootball: player, played, wins, draws, losses, goals for, goals against, goal difference and points
